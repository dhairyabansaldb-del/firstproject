# Production Runbook

This document contains standard operating procedures for deploying, maintaining, and troubleshooting the AI Restaurant Recommendation System.

## Deployment Setup

### Backend (Railway)
1. Login to Railway and select **New Project > Deploy from GitHub repo**.
2. Select the `dhairyabansaldb-del/firstproject` repository.
3. Under **Variables**, add the following:
   - `GROQ_API_KEY`: Your active Groq API Key.
4. Railway will automatically detect the `Procfile` and `requirements.txt` to run the Nixpacks Python builder.
5. The build process will execute `start_backend.sh`, which automatically downloads the Zomato dataset, meaning you don't need to manually upload the 12MB file!
6. Once deployed, click on the **Settings** tab and select **Generate Domain** to get your public URL (e.g. `https://restaurant-reco-backend.up.railway.app`).

### Frontend (Vercel)
1. Login to Vercel and select **Add New > Project**.
2. Import the `dhairyabansaldb-del/firstproject` repository.
3. Crucial Step: Expand **Build and Output Settings** and set the **Root Directory** to `phases/phase-5/frontend`.
4. Before clicking Deploy, open `vercel.json` in your repository and update `<YOUR_RAILWAY_URL>` with the domain generated by Railway.
5. Click **Deploy**. Vercel will host the static assets and securely proxy all API requests to the Railway backend.

## Troubleshooting

### Issue: "Something went wrong" (Generic Frontend Error)
- **Cause:** Vercel cannot reach Railway (Timeout or 5xx).
- **Resolution:** 
  1. Check Railway logs for application crashes.
  2. Verify that the `<YOUR_RAILWAY_URL>` in `vercel.json` matches exactly.
  3. Ensure `GROQ_API_KEY` is present in Railway variables.

### Issue: AI explains "Ranked X based on rating" instead of custom categories
- **Cause:** The `GROQ_API_KEY` is missing or invalid, causing the fallback to deterministic ranking.
- **Resolution:** Check the environment variables in Railway. Restart the Railway instance.

### Issue: Missing Data / FileNotFoundError on Railway
- **Cause:** The HuggingFace ingestion script failed during the build phase.
- **Resolution:** Force a re-deploy on Railway to re-run `start_backend.sh`.
