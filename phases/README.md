# Phase Folders

Each phase implementation is isolated in its own folder to keep incremental changes easy to track.

- `phase-1/` - initial data pipeline and catalog service implementation
- `phase-2/` - architecture Phase 2 implementation with ingestion quality report
- `phase-3/` - typed preference intake and deterministic filtering preview API
- `phase-4/` - Groq-powered LLM ranking with strict JSON and fallback path

You can add future folders as:
- `phase-3/`
- `phase-4/`
- etc.
